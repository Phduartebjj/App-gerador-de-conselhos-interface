# Advice Generator App

## 📌 Sobre o projeto
Aplicativo web simples que gera conselhos aleatórios e permite tradução para diferentes idiomas utilizando APIs externas.

## ⚙️ Como funciona
- Ao clicar no botão, um conselho aleatório é gerado via API.
- O conselho padrão vem em português.
- O usuário pode alternar o idioma clicando nas bandeiras.

## 🧠 Funcionalidades
- Geração de conselhos aleatórios.
- Tradução dinâmica de conteúdo.
- Seleção de idioma via interface (PT / ES).
- Integração com APIs externas.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- MyMemory Translate API
- Advice Slip API

## 🎯 Objetivo
Projeto desenvolvido para praticar consumo de APIs, manipulação do DOM e controle de estado no frontend.
